# Registered multi-view scans

**Goal:** Implement phase 7 without assuming repeated icons establish physical identity. No tests or screenshot corpus execution, per user instruction.

Each view records an archived screenshot hash, manually registered absolute cell origin and visible dimensions, complete visible-cell coverage confirmation and the incumbent local draft. Views belong to one unchanged container layout. Cells seen in multiple views require an explicit authoritative view selection; matching item IDs never resolve physical identity. A stack must be wholly selected from one view. A selected fragment of a footprint blocks composition rather than clipping/counting part of it. Legitimate equal items at different coordinates stay separate. All source observations are preserved with globally translated locations/pixel registration.

## Partial patch backend

`commitPartial` now consumes the saved registered composition only for a partial session at the expected container revision and with a baseline snapshot. It recomputes the composition, requires reviewed views/stable layout, and replaces only wholly covered baseline footprints. An existing footprint intersecting both seen/unseen cells is rejected. Unseen stacks retain identities, quantities, FIR, confirmations, original screenshot hashes and protection; their provenance points to the retained baseline snapshot rather than a missing observation in the new session. Baseline protection is also conservatively retained on replacement footprints.

The transaction writes the new snapshot, finalized draft and observations, committed session state and replay journal together. Replay resolves before external evidence reads. New commits verify every registered screenshot (including empty views) and retained evidence. Undo uses the incumbent previous-snapshot chain. Partial results always have fullCoverage=false, so unseen historical regions cannot authorize SELL as freshly inspected inventory; a later reviewed full scan is required to restore complete coverage. Partial patch UI/preview of retained facts is still pending.
