## Frontend integration

`FootprintReconciliation` selects one boundary fragment per saved source, excludes consumed/recursive parts and limits displayed candidate rows to 50 with search. A new joined output starts with unknown identity/quantity/FIR and no inherited state facts or confirmations. The editor shows source rectangles and archived fragment pixels, independent identity/amount/FIR/dogtag/durability/protection controls, a same-physical-item assertion and a separate complete-output review assertion. Changing facts withdraws review; identity/orientation changes withdraw dependent facts/confirmations. Native coverage/intersection/authority validation remains authoritative. There is no automatic summation or icon-based matching.

`JoinedSourceReview` displays one selected archived fragment at a time, or the full screenshot with an explicit notice when manual source registration lacks a pixel grid. Loading/error feedback never confirms facts. The selector blocks rapid overlapping source reads; late completions are discarded and decoded bitmaps/object URLs are closed/revoked on cleanup. Stable source registration keys prevent reloading images on unrelated fact edits. The same viewer is available in final physical stack review; incomplete multi-source pictures cannot feed whole-item learning/quantity OCR.

Current catalog footprint/orientation and independently confirmed quantity checks gate composition application/partial commit, including resumed reviewed joins. Unknown identity may remain explicit; unknown physical facts continue to block SELL through the existing planner. Joins remain in memory until the registered composition is saved, with visible feedback. Full-composition application now saves its source composition before replacing the editor for final review. Partial commits retain their explicit approval, CAS/replay and mixed-age protection. Source replacement/removal invalidation from the backend checkpoint remains connected.
