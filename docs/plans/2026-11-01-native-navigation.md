# Shared Tauri navigation boundary

Goal: preserve the audit's trusted-local-window/IPC boundary after replacing Electron. Source review found both native windows permitted every tauri/asset URL and every HTTP localhost/127.0.0.1 port. That permits unintended local server pages to replace the trusted UI; window labels alone are not an origin policy.

Use one navigation guard for main and searchbar. Permit embedded tauri://localhost without a port and the current Windows http://tauri.localhost origin on its default port. Reject URL credentials. Permit a configured HTTP(S) devUrl origin only when the installed Tauri runtime's public is_dev() reports development mode. Compare scheme/host/effective port through URL origin equality, not a hostname allowlist. HashRouter paths/fragments remain unrestricted within that origin. Top-level asset:// pages, arbitrary loopback services, nonstandard embedded ports and other schemes/hosts are rejected. Existing external-link opener validation remains separate and unchanged.

Inspected the installed Tauri 2.12.5 manager source for embedded protocol origins/get_app_url and its public is_dev helper; this avoids inferring runtime mode from Rust debug flags. Existing config uses the HTTP Windows protocol origin, not the optional HTTPS-scheme variant. A future switch to that mode must update this boundary deliberately.
